# 📈 Stock Market Analytics Dashboard

## Overview

This project is an interactive Stock Market Analytics Dashboard developed using Python, Streamlit, Pandas, Plotly, and Yahoo Finance API.

The dashboard helps analyze stock price trends, moving averages, trading volume, daily returns, and risk metrics.

---

## Features

- Real-time stock data using Yahoo Finance API
- Stock price trend analysis
- Moving average analysis
- Daily returns analysis
- Risk and volatility analysis
- Candlestick chart visualization
- Portfolio comparison
- Interactive dashboard using Streamlit

---

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Yahoo Finance API
